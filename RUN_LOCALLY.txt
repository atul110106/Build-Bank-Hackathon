BharosaLoan — run on your local system
======================================

Requirements:
- Node.js 18+ (https://nodejs.org)
- npm (comes with Node.js)

Steps:
1. Unzip this folder
2. Open a terminal inside the unzipped folder (the one that contains package.json)
3. Run:

   npm install
   npm run dev

4. Open your browser at:

   http://localhost:3000

5. Click "Explore BharosaLoan"

Notes:
- No bank login is required for BharosaLoan
- Demo banking login (optional): demo@securebank.test / hackathon
- Keep the terminal open while using the app
- Stop the server with Ctrl + C
